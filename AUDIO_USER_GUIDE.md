# 🔊 Audio Feature - User Guide

## How to Use the Audio Feature

### 1. Ask AI a Question
Type any fitness question in the AI chat:
- "How to train back with only three exercises?"
- "What should I eat for muscle gain?"
- "Explain proper squat form"

### 2. Get AI Response
The AI will generate a detailed response with:
- ✅ Markdown formatting
- ✅ Emojis and icons
- ✅ Bullet points and sections
- ✅ Exercise instructions

### 3. Listen to the Response
Look for the audio controls below each AI message:

```
⏰ 2m ago | 🔊 Listen
```

Click the **"🔊 Listen"** button to hear the response!

### 4. Audio Playback
When playing, you'll see:

```
⏰ 2m ago | ⏹️ Stop  [~~~]
              ↑       ↑
           Button  Animation
```

- **Stop button**: Click to stop playback
- **Animated wave**: Shows audio is playing
- **Blue highlight**: Indicates active playback

### 5. Stop Anytime
Click the **"⏹️ Stop"** button to stop the audio at any time.

## 🎯 Features

### What Gets Read:
- ✅ Full AI response text
- ✅ Automatically cleaned (no markdown symbols)
- ✅ Natural pauses between sections
- ✅ Clear pronunciation

### What's Removed:
- ❌ Markdown symbols (##, **, *)
- ❌ Emojis (for better speech)
- ❌ Code blocks
- ❌ Special formatting

### Example:
**AI writes:**
```markdown
## 💪 Back Training

Here's a **comprehensive** workout:
1. Pull-ups
2. Rows
```

**TTS reads:**
```
Back Training. Here's a comprehensive workout. Pull-ups. Rows.
```

## 🔧 Troubleshooting

### No Sound?
1. Check device volume
2. Check browser permissions (allow audio)
3. Try refreshing the page
4. Check if device TTS is enabled

### Poor Quality?
- Quality depends on your device's built-in TTS
- Try different browsers (Chrome usually best)
- Consider using headphones

### Not Working?
1. Refresh the page
2. Clear browser cache
3. Check browser console for errors
4. Try a different browser
