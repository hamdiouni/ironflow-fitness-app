# IronFlow Copy & Voice Guide

This document defines the tone of voice and vocabulary standards for IronFlow.

---

## 1. Core Principles

1. **Clear & Direct**: Everyday English that any gym-goer understands instantly.
2. **Encouraging & Grounded**: Speak like an experienced, supportive strength coach.
3. **No Sci-Fi / Military / Robotic Jargon**: IronFlow is a premium fitness app, not a spaceship terminal or a military database. Technical and robotic words confuse real users and create barriers to entry.
4. **Action-Oriented**: Buttons and labels should describe concrete, immediate physical actions (e.g., "Start Workout", "Log Weight", "Create Account").

---

## 2. Vocabulary Replacement Dictionary

| Avoid (Sci-Fi / Robotic Jargon) | Use Instead (Simple English) | Context |
|---|---|---|
| **Operator** | You / Athlete / Member | User identity and account |
| **Operator Identifier** | Email Address | Login and signup fields |
| **Operator Callsign** | Your Name / Full Name | Registration name field |
| **Authenticate Operator** | Log In | Authentication buttons |
| **Initialize Operator** | Create Account | Registration buttons |
| **Security Cipher / Cipher** | Password | Authentication fields and errors |
| **Directive** | Plan / Workout Plan / Routine | Training schedules and reminders |
| **Today's Directive** | Today's Workout | Daily action cards |
| **Recovery Directive** | Rest & Recovery | Rest day cards |
| **Telemetry** | Stats / Progress / Measurements | Charts, history, metrics |
| **Biometric Telemetry** | Body Stats / Measurements | Weight, height, circumference |
| **Daily Fuel Telemetry** | Daily Nutrition Summary | Food and macro tracking |
| **Neural Core / AI Core** | AI Coach / IronFlow AI | AI assistant dialogs and headers |
| **Calibrate / Calibration** | Set Up / Update / Log | Onboarding and profile editing |
| **Initialize** | Start / Set Up / Create | Starting onboarding or sessions |
| **Terminate Session** | Log Out | Account sign-out dialogs |
| **Eradicate Telemetry** | Delete History / Clear Data | Danger zone settings |

---

## 3. Screen-Specific Examples

### Authentication (Login & Sign Up)
- **Before**: "OPERATOR AUTHENTICATION", "SECURITY CIPHER", "Authenticate operator credentials to decrypt telemetry records"
- **After**: "WELCOME BACK", "PASSWORD", "Sign in to access your workout and nutrition history"

### Home & Today Dashboard
- **Before**: "TODAY'S PROTOCOL DIRECTIVE", "EXECUTE TODAY'S DIRECTIVE", "DAILY FUEL TELEMETRY"
- **After**: "TODAY'S WORKOUT PLAN", "START TODAY'S WORKOUT", "DAILY NUTRITION SUMMARY"

### Profile & Settings
- **Before**: "BIOMETRIC ID & DIRECTIVES", "CALIBRATE BIOMETRICS & GOALS", "TERMINATE SESSION"
- **After**: "PROFILE & WORKOUT PLAN", "EDIT BODY STATS & GOALS", "LOG OUT"

### Progress & Measurements
- **Before**: "BIOMETRIC & PERFORMANCE TELEMETRY", "LATEST TELEMETRY"
- **After**: "PERFORMANCE & BODY STATS", "BODY MEASUREMENTS"

### AI Assistant
- **Before**: "OPERATOR // QUERY", "AI CORE // ADVISORY"
- **After**: "You", "Coach"
