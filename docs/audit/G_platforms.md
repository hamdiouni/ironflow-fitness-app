# Audit Track G — Platforms (Android, iOS, Web, PWA, Wasm)

| ID | Severity | Finding | Measured Evidence | Prescribed Fix | Effort | Wave |
| :--- | :---: | :--- | :--- | :--- | :---: | :---: |
| **PLT-01** | **P1 HIGH** | Cold-start notification permission prompt blocks `runApp()` | `lib/main.dart:105`: `await notificationService.requestPermissions();` executes synchronously inside `main()` before `runApp()`. On Android 13+ and iOS, this triggers a system permission dialog on a blank splash screen before onboarding/login and slows cold start. | Remove `requestPermissions()` from `main()`; trigger notification permission contextually when the user enables reminders or starts their first rest timer. | 2h | W5.1 / W5.3 |
| **PLT-02** | **P1 HIGH** | Missing iOS `PrivacyInfo.xcprivacy`, `NSCameraUsageDescription`, and `Podfile` | `ios/Runner/PrivacyInfo.xcprivacy` does not exist (mandatory for Apple App Store since May 2024 when using `shared_preferences`/`NSUserDefaults`, file timestamp APIs, etc.). `ios/Runner/Info.plist` has `NSPhotoLibraryUsageDescription` but lacks `NSCameraUsageDescription` (causes immediate crash if `image_picker` opens camera on iOS) and lacks `CFBundleURLTypes` for Google Sign-In. | Add `ios/Runner/PrivacyInfo.xcprivacy` declaring required-reason APIs (`CA92.1`, `C617.1`), add `NSCameraUsageDescription` and `CFBundleURLTypes` to `Info.plist`, and commit an explicit `ios/Podfile` targeting iOS 14.0+. | 4h | W5.3 |
| **PLT-03** | **P1 HIGH** | Android release build lacks R8 shrinking, ABI splits, and flavors | `android/app/build.gradle.kts:62-71`: `buildTypes.release` does not enable `isMinifyEnabled = true` or `isShrinkResources = true`, and no `productFlavors` (`dev`, `staging`, `prod`) are configured. Resulting fat APKs are 231.8 MB (debug) and 97.7 MB (profile) / 72 MB (release). | Configure `dev`, `staging`, `prod` flavors in Wave 2.5, enable R8 shrinking (`isMinifyEnabled = true`, `isShrinkResources = true`) with ProGuard rules for Hive/Firebase/Gson in Wave 5.1/5.3, and build AAB / per-ABI splits (`--split-per-abi`). | 6h | W2.5 / W5.1 / W5.3 |
| **PLT-04** | **P1 MEDIUM** | Web Wasm blockers (`flutter_secure_storage_web` & `flutter_tts`) | `flutter_secure_storage: 9.2.4` pulls `flutter_secure_storage_web: 1.2.1` (`dart:html`, `dart:js_util`); `flutter_tts: 4.2.0` uses legacy JS interop. | Keep JS web build + PWA solid first; upgrade `flutter_secure_storage` to `^11.2.0` in Wave 3.1 and abstract TTS behind a web-safe interface in Wave 5.2 before benchmarking `--wasm`. | 4h | W3.1 / W5.2 |
