# Audit Track E — State Management (Riverpod)

| ID | Severity | Finding | Measured Evidence | Prescribed Fix | Effort | Wave |
| :--- | :---: | :--- | :--- | :--- | :---: | :---: |
| **STM-01** | **P1 HIGH** | 100% of stateful notifiers still use legacy `StateNotifier` (30 classes, 0 `Notifier`/`AsyncNotifier`) | Contrary to the old report's claim ("28 old vs 27 new"), AST/regex scan confirms **30 `StateNotifier` classes**, **28 `StateNotifierProvider` declarations**, **0 `Notifier` classes**, **0 `AsyncNotifier` classes**, and **0 `@riverpod` annotations** across `lib/`. | Migrate all 30 `StateNotifier`s to plain Riverpod `Notifier` / `AsyncNotifier` (`NotifierProvider` / `AsyncNotifierProvider`) feature by feature with characterization tests first (see ADR-003). | 14h | W3.2 |
| **STM-02** | **P1 MEDIUM** | Unused `riverpod_annotation` and `riverpod_generator` packages | `pubspec.yaml` declares `riverpod_annotation: ^2.6.1` and `riverpod_generator: ^2.6.4`, but 0 files use `@riverpod`. Keeping `riverpod_generator` pins `analyzer` and slows down `build_runner`. | Per ADR-003, use plain `Notifier` / `AsyncNotifier` (zero code-gen build-time overhead) and remove `riverpod_annotation` + `riverpod_generator` (ASK). | 1h | W3.2 |
| **STM-03** | **P1 MEDIUM** | Giant `GlobalAINotifier` (`1,098 LOC`) mixing orchestration, caching, and UI state | `lib/features/ai/presentation/providers/global_ai_provider.dart` is 1,098 lines long and directly coordinates multiple services, fallbacks, and state slices. | Split `GlobalAINotifier` into focused domain use cases and smaller `AsyncNotifier` providers (`aiChatNotifierProvider`, `aiInsightsNotifierProvider`, `aiQuotaProvider`). | 6h | W3.2 / W3.3 |
| **STM-04** | **P2 LOW** | Inconsistent loading/error patterns (`isLoading`/`error` fields vs `AsyncValue`) | Custom state classes (`AuthState`, `WorkoutState`, `NutritionState`, `GlobalAIState`) manually track `bool isLoading` and `String? error` instead of leveraging `AsyncValue<T>`. | Standardize asynchronous state slices on `AsyncValue<T>` during the Wave 3.2 `AsyncNotifier` migration. | 6h | W3.2 |
